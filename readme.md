# 🍽️ F&B Performance Intelligence System

Turn raw sales data into clear, actionable business insights in seconds.

---

## 🚀 Overview

Most small F&B businesses rely on intuition to make decisions.

This system transforms your **POS / Excel / CSV data** into a simple dashboard that shows:

* What products actually make you money
* When your peak hours happen
* Where revenue is being lost

Built with Python + Streamlit, designed for **real-world F&B operations**.

---

## ⚡ Key Features

* 📊 **Instant Sales Dashboard**

  * Total revenue
  * Total orders
  * Daily trends

* 🥇 **Top-Selling Products**

  * Identify best performers
  * Spot low-performing items

* ⏰ **Peak Hour Analysis**

  * Understand customer flow
  * Optimize staffing decisions

* 📉 **Revenue Patterns**

  * Track growth or decline over time

* 🧠 **Auto-Generated Insights**

  * Simple explanations (not just charts)
  * Helps non-technical owners make decisions fast

---

## 📂 Input Format

Upload a CSV or Excel file with columns like:

* `date` / `time`
* `product_name`
* `quantity`
* `price`
